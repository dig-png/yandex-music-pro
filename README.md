# YandexMusicPro — установка и первый запуск

Расширение для Chrome: скачивает музыку с music.yandex.ru, учитывает уже скачанные файлы
и показывает, чего не хватает в локальной фонотеке по сравнению с аккаунтом.

Что умеет:

- «Не скачивать то, что уже есть на диске» — кнопки скачивания пропускают треки, найденные в папке.
- Сверка «Мне нравится», плейлистов и альбомов аккаунта с файлами на диске.
- Отчёт: чего не хватает, что найдено, что лишнее, дубликаты, слабые совпадения.
- Если трек есть только в MP3 — докачивает FLAC, а MP3 убирает в `_replaced_mp3`.
- Скачанное сразу попадает в вашу папку с музыкой.

Локальные файлы читает отдельный помощник на Node.js (native messaging). В интернет ничего
не отправляется: расширение ходит только на `music.yandex.ru`.

---

## 1. Что нужно

- Windows, Chrome (или Edge).
- [Node.js](https://nodejs.org) — обычная установка, `node` должен быть в PATH.
  Проверить: откройте PowerShell и выполните `node -v`.

## 2. Установить локальный помощник

Откройте PowerShell в папке проекта (или укажите полный путь к `install.ps1`) и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File ".\native\install.ps1"
```

Скрипт скопирует помощника в `%LOCALAPPDATA%\YandexMusicPro\helper` и пропишет его
для Chrome и Edge в реестре текущего пользователя. ID расширения закреплён, так что
после переустановки расширения ничего перенастраивать не нужно.

Если Chrome был открыт — перезапустите его, чтобы он увидел помощника.

## 3. Загрузить расширение

1. Откройте `chrome://extensions/`.
2. Включите **Режим разработчика** (переключатель справа сверху).
3. Нажмите **Загрузить распакованное расширение** и выберите папку проекта
   (ту, в которой лежит `manifest.json`).

4. Расширение появится в списке с ID `hjcmcnhpcefhhkhgcfjmodggncllnedo`.
   Закрепите его на панели (иконка пазла → булавка).

Обновлять расширение после правок: кнопка «Обновить» на карточке в `chrome://extensions/`.

## 4. Первая настройка

1. Войдите в аккаунт на [music.yandex.ru](https://music.yandex.ru) и оставьте вкладку открытой.
2. Откройте настройки расширения (иконка → «Настройки»).
3. В блоке **Локальная музыка** укажите папку с музыкой, например:

   ```
   C:\Users\<ваше имя>\Music\music
   ```

   Можно вставить путь из проводника. Папка должна существовать.

4. Нажмите **Проверить помощника** — должно появиться
   «Помощник работает (Node v…). Папка найдена.».
5. Нажмите **Обновить список файлов** — расширение прочитает теги всех файлов
   (около секунды на 1000 файлов) и покажет «Готово: N файлов».
6. В блоке **Сверка библиотеки** выберите источники («Мне нравится», плейлисты, альбомы)
   и нажмите **Проверить библиотеку**. Нужна открытая вкладка music.yandex.ru с вашим аккаунтом.
7. Нажмите **Открыть отчёт**.

## 5. Как пользоваться отчётом

Вкладки:

| Вкладка | Что показывает |
| --- | --- |
| **Не хватает** | Треки из Яндекса, которых нет на диске |
| **Найдено** | Совпадения по артисту и названию |
| **Слабые совпадения** | Похожие файлы без артиста в тегах — проверьте вручную |
| **Лишние** | Файлы на диске, которых нет в выбранных источниках |
| **Дубликаты** | Несколько файлов на один трек (например, MP3 и FLAC) |

Кнопки:

- **Скачать отсутствующие** — скачивает всё со вкладки «Не хватает» (или только отмеченные
  галочками треки). Прогресс виден внизу страницы, можно остановить.
- **CSV / JSON** — выгрузить отчёт.
- **Обновить список файлов** / **Проверить библиотеку** — пересобрать данные, не уходя из отчёта.

Если трек есть только в MP3, в статусе будет «Есть MP3 → нужен FLAC»: такой трек попадёт
в «Не хватает» и будет докачан в FLAC.

## 6. Скачивание на сайте

На страницах music.yandex.ru у треков и альбомов появляются кнопки скачивания.
Уже скачанные треки помечаются как выполненные и пропускаются, в том числе в кнопке
«Скачать все треки». Скачанное автоматически переносится в папку из настроек.

Куда что попадает:

- Новые файлы — сразу в папку из настроек (плоская структура, имя `Артист - Название.ext`).
- Заменённые MP3 при апгрейде до FLAC — в подпапку `_replaced_mp3` внутри папки с музыкой,
  их можно удалить вручную, когда убедитесь, что FLAC на месте.

## 7. Настройки, которые стоит знать

- **Если трек есть только в MP3**: «Докачать FLAC…» (по умолчанию) или «Считать скачанным — MP3 достаточно».
- **Перемещать скачанное в папку с музыкой** — иначе файл останется в загрузках Chrome.
- **Формат** — FLAC (по умолчанию) или MP3; для MP3 есть выбор битрейта.
- **Теги и обложка** — артист, название, альбом, год, размер обложки.
- **Сохранять в подпапку** — по умолчанию выключено, чтобы структура оставалась плоской.

## 8. Если что-то не работает

**«Помощник не найден» / «Помощник не отвечает»**
- Проверьте `node -v` в PowerShell.
- Перезапустите Chrome и повторите установку помощника (шаг 2).
- Проверьте, что существует `%LOCALAPPDATA%\YandexMusicPro\helper\com.ymp.files.json`.

**«Не удалось войти в аккаунт…»**
- Откройте music.yandex.ru, войдите в аккаунт, оставьте вкладку открытой и повторите проверку.
- Если вкладка была открыта давно, обновите её (F5).

**«Нужно обновить список файлов в папке»**
- Нажмите «Обновить список файлов» — расширение не знает о файлах, появившихся после последнего скана.

**Трек есть, но помечен как отсутствующий**
- Проверьте теги файла: должны быть заполнены артист и название. Файлы без артиста попадают
  в «Слабые совпадения».
- Разные версии (remix, live, feat.) считаются разными треками — это ожидаемо.

**Скан идёт долго**
- Это нормально для больших папок: чтение тегов идёт через помощника и занимает несколько секунд
  на тысячу файлов. Повторный скан быстрее.

## 9. Удаление

```powershell
powershell -ExecutionPolicy Bypass -File ".\native\uninstall.ps1"
```

Затем удалите расширение на `chrome://extensions/`. Музыка и папка `_replaced_mp3` не затрагиваются.
